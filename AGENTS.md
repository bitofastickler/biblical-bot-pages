# Open Study Pages

This is the independent static replacement. Do not modify the sibling `biblical-bot-app` checkout or its deployments while working here.

Keep the app useful without AI and free of authentication, server dependencies, payment systems, runtime third-party requests, and credentials. Maintain accessible mobile/desktop reading and safe portable study files. Scripture is the source; commentary is clearly separate. Do not alter Bible wording or relabel translations.

Run `npm test` and `npm run build`; after study file or UI changes also run `npm run test:browser` with the local server running. Test the project subpath and a fresh browser file round trip. Preserve strict import limits, plain-text rendering, replacement protection, and download-as-new-snapshot semantics. Never commit `.local`, personal studies, database exports, or environment files.

Deploy through the Pages workflow only. Retirement of old infrastructure is a separate, explicitly authorized operation described in `docs/migration-and-retirement.md`.
