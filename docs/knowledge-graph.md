# Bible graph integration

The static reader now has a discoverable Graph entry and a passage-specific link. The graph retains the original 3D explorer, accessible list selection, search, chapter scopes, focused connections, exact evidence and uncertainty notes. Its verse panel links to the reader; browser Back/Forward restores graph selections and reader references. Repeated selection does not add duplicate history entries. Non-Genesis books show an explicit unavailable graph state while remaining fully readable.

Only selected Genesis annotations are shipped: 193 entities, 293 relationships, 2,435 mentions, 1,533 verses and 40 uncertainty records. The 43 tracked omissions are resolved and no selected entities are isolated. None of these counts means exhaustive or expert-certified coverage.

## Extension contract

Verse IDs use canonical book codes, such as `GEN.14.17`. Existing entity IDs such as `bg:abram` are permanent; do not prefix or rename them during integration. Entity identity across books must be reviewed, not inferred from names. New datasets can be registered with distinct canonical book IDs, graph/verse asset paths, reader book mapping, chapter count and scope ranges. Runtime loading and reader links consume that registry. Add a tested dataset builder, quality expectations and book-specific review before enabling any new book; the present builder and Quality page remain Genesis-specific. This is an extension boundary, not a completed multi-book corpus.

URLs are relative and require no server rewrites: `graph/?book=GEN&entity=bg%3Aabram&verse=GEN.14.17` and `#Genesis%2014%3A17`. The list and evidence buttons provide keyboard access independently of the canvas. Mobile browser widths are tested; physical touch hardware is not certified.

## Build and checks

Use Node 24+, Python 3.12+ and the locked npm dependencies. Run `npm test`, `npm run build`, `npm run dev`, then `npm run test:browser`. The build invokes the original 11 release-boundary tests and 31 dataset tests and refuses to copy graph assets on a failed/stale gate. The browser command includes the original Chromium-to-Firefox study-file round trip plus graph navigation checks at 1440, 390 and 320 pixels. Local screenshots/results stay under ignored `.local/`.

The release wrapper propagates UTF-8 mode to Python subprocesses on Windows. In this Windows sandbox, set TMP/TEMP to an approved writable temp directory when needed. Set `PLAYWRIGHT_BROWSERS_PATH` to the existing browser cache if the sandbox redirects LocalAppData. These are test environment accommodations, not application requirements.
